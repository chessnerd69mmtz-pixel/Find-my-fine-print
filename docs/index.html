Find what the fine print actually says.

Search contracts and rulebooks, verify verbatim passages, and flag potential ambiguities. Ollama runs locally by default without an API key or per-request API fees. Gemini and Groq are optional hosted providers.

Choose where analysis runs

Local is selected by default. Your contract stays on your computer when using your own local backend and Ollama. Cloud analysis sends the document to the cloud backend and then to the selected AI provider.

Local mode requires the companion Python app running on your computer at http://127.0.0.1:8000.

PDF, DOCX, TXT, Markdown · Up to 50 MB by default. Scanned PDFs need OCR first.

Ollama is the default. Cloud providers send retrieved document sections to their API and follow their own quotas, terms and possible charges.

Your key is used for the current request and is not written to a settings file or database. Only use this local app on a trusted computer.

Ollama model name. Default: llama3.2.

All sections reviews every extracted chunk and can take a long time on large documents. Local use has no per-request API fee, but speed depends on your computer.

Ready when you are

Choose a document and ask a specific question to begin. For local analysis, start the companion app. For cloud analysis, enter your deployed backend URL and choose Gemini or Groq with your own key.

When using Gemini or Groq, the retrieved document sections needed for analysis are sent to that provider. Avoid uploading confidential or privileged documents unless you have checked the provider's privacy terms and are authorised to share them. API keys are never included in the repository. Find My Fine Print is an informational tool, not a law firm or a substitute for qualified legal advice. Local AI can miss context or misinterpret legal effect. Exact quotes and source offsets are checked against extracted text. Findings without an exact supporting quote are marked unverified. Verify evidence in the original file before relying on it.
